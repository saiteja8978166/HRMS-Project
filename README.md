# HRMS - Human Resource Management System

A Java console-based Human Resource Management System using MySQL and JDBC.

## Features
- Organization Registration and Login
- Employee Management
- Attendance Management
- Salary and Payroll Management
- Notice Management
- Holiday Management
- MySQL Database Integration

## Technologies Used
- Java
- MySQL
- JDBC
- IntelliJ IDEA

## How to Run
1. Install Java JDK and MySQL.
2. Create the `hrms_db` database and required tables.
3. Configure your database connection in `DatabaseConnection.java`.
4. Add MySQL Connector/J to the project.
5. Run the `HRMS` main class in IntelliJ IDEA.
